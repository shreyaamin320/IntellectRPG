# IntellectRPG 🎮

A gamified study tracker built with Python and Tkinter.

## 🚧 Project Status

Currently in development.

This project is being built from scratch as part of the FirstCommit hackathon.

## 🎯 Goal

IntellectRPG will turn studying into an RPG-style experience where users can:

- Create study quests
- Complete quests
- Earn XP
- Level up
- Track their progress

More features will be added as development continues.

## 🛠️ Built With

- Python
- Tkinter
- CustomTkinter
